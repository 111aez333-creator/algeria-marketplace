# سوق الجزائر — خطوات النشر (GitHub Pages + Firebase)

## ترتيب النشر (مهم)
1. **أنشئ الفهارس أولاً** (تاخذ بضع دقائق): Firebase Console → Firestore Database → **Indexes** → Composite → **Add index**.
   Collection ID: `listings`، Query scope: **Collection**، وأضف 3 فهارس:
   - `category` Ascending + `createdAt` Descending
   - `wilaya` Ascending + `createdAt` Descending
   - `keywords` **Array contains** + `createdAt` Descending

   (إذا نسيت واحد، يظهر في Console المتصفح خطأ فيه رابط أزرق: انقر عليه ويتكوّن الفهرس تلقائياً. كلّ فهرس يخدم فلتر: القسم، الولاية، البحث بالكلمة.)
2. **ارفع ملفات الموقع على GitHub** (كلها من الـ zip) وانتظر دقيقة حتى يتحدّث GitHub Pages.
3. **انشر القواعد مباشرة بعدها** (في نفس الدقيقتين): Firestore Database → **Rules** → الصق `firestore.rules` → **Publish**.
   القواعد الجديدة والنسخة الجديدة من الموقع يتلازمو: نسخة قديمة مع قواعد جديدة (أو العكس) تفشل في نشر الإعلانات.
4. **الأدمن:** افتح `/admin.html` بحساب `111aez333@gmail.com` واضغط **🔎 فهرسة الإعلانات القديمة للبحث** مرة وحدة (باش تظهر الإعلانات القديمة في البحث بالكلمات).
5. **جرّب بحساب عادي:** انشر إعلان، (الثاني خلال دقيقة لازم يرفض)، افتح إعلان، قيّمو، راسل، واطلب توصيل.

## ما تبدّل
- **التصفح بالصفحات:** الرئيسية 12 قراءة، والبحث 24 إعلان فكل صفحة مع زر "عرض المزيد". المفضلة تتجاب بالمعرّف. السائقون والترويجات بقراءات محدودة.
- **البحث:** بالكلمة الكاملة (مثلاً "هواتف"، ماشي جزء من الكلمة). فلتر واحد يمشي للسيرفر (كلمة ثم قسم ثم ولاية) والباقي في المتصفح.
- **ضد السبام:** فاصل 60 ثانية + 20 إعلان فكل 24 ساعة (القواعد تفرضها)، ممنوع رابط في العنوان، honeypot في النماذج، فواصل للرسائل والبلاغات وطلبات التوصيل، وزر أدمن "إيقاف + إخفاء إعلاناته".

## تذكير
- **App Check:** بعد ما تتأكد أن طلبات Firestore Verified، فعّل **Enforce**.
- **Cloudinary:** فـ upload preset `Storedz`: حدّد الصيغ (jpg, png, webp) وحد الحجم وفولدر ثابت.
- **تنظيف قديم:** احذف collection `driverKyc` وحقول `idCardUrl/selfieUrl` من `deliveryRequests`، وصور الهوية القديمة من Cloudinary.
- `firebase.json` و`.firebaserc` و`firestore.indexes.json` اختيارية (للي يستعمل Firebase CLI).
